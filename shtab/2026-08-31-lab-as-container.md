## Тезис

Владелец поручил лаборатории Grok **самой развиваться и масштабироваться** и заранее готовиться к тому, что эту команду **возьмут в AICM как контейнер или контейнеры**.

Это не «Grok = AICM». Это **сменный исследовательский слой**: роли, пакеты, freeze и I/O, которые позже можно клонировать в другой runtime.

**LAB-C-01.** Default: **один** контейнер на исследовательский центр. Восемь ролей — процессы внутри, не восемь микросервисов.

**LAB-C-02.** Второй контейнер (replay: Механик + Тестер) — только гипотеза. Условие: замороженный I/O (спека контура + публичный датасет + отчёт). Без этого — не дробить.

**LAB-C-03.** Масштаб = фишки на существующих ролях + пропуск пакетов. Не плодить ботов. Не плодить пустые репо.

**LAB-C-04.** Хост Grok Bot (чат, плагины MCP, X `@acapitalmanager` read-only) — **адаптер**. Его можно сменить. Он не личность AICM и не копируется в Foundation.

**LAB-C-05.** Стык на выходе: приватный `Seryogapahom/AICM-docs` (`AGENTS.md` + дерево папок). Foundation/Hermes позже **клонирует пакеты**, не чат Grok.

Торговля — первый экономический срез, не identity системы. Слои стратегий не склеивать без Consilium основной системы. Consilium здесь не строим.

## Что такое «команда», что такое хост

### Команда (копируемый контур ролей)

| Роль | Процесс в контейнере | Пишет (логически) | Не пишет |
|---|---|---|---|
| Штаб | очередь, штамп пакета, архив | `shtab/`, README, AGENTS, решение что класть | Hermes, live, новые боты |
| Разведчик | внешний съём | `razvedka/` | сверки «кто прав», канон |
| Аналитик | сопоставление слоёв | `sverki/` | гибрид, перезапись чужих пакетов |
| Твиттер | novinki с X | `razvedka/novinki/` | посты, follow, live |
| Механик | спека контура | `kontury/` (спека) | live, гибрид слоёв |
| Тестер | исторический replay | `kontury/` (отчёт) | live, подбор «пока красиво» |
| Канонист | карточки сессий | `kanon/sessions/` | reopen L0–L2 |
| Картограф | единая карта | `kanon/` | канон Гермеса |
| Трейдер | нет | — | живые сделки |
| Владелец | External Enabler | ничего | проектирование, ревью, кнопка |

Два цикла (не боты):

- Понедельник 09:00 — гигиена дерева + sweep provenance/противоречий (HQ-07). Не amendment канона.
- Будни 10:00 — сбор (X + инкремент не-X) **и** один шаг переработки. Штамп KC целиком (HQ-03). Не 12 вопросов Владельцу.

### Хост (не копировать как identity)

- UI чата Grok Bot и персона агента.
- PAT / сессия GitHub, сессия X, cookie браузера, MCP-аккаунты.
- Рабочий стол «компьютера агента», локальные пути хоста.
- Плагины как продукты (Tally, Qualtrics, Letta-as-SaaS) — не ставить identity лабы.
- Playbook внедрения Hermes / Codex master order v2.

## Контракт контейнера

**LAB-C-06. Вход.** Brief штаба, URL, уже снятый пакет, спека контура, публичный датасет. Не анкета Владельца. Не HITL-оператор.

**LAB-C-07. Выход.** Markdown-пакет с шапкой Knowledge Candidate: статус, дата, источник, provenance. Индекс папки обновляется отдельным коммитом. Без источника файл в архив не принимать.

**LAB-C-08. Freeze.** `AGENTS.md` — закон записи. `shtab/ramka.md` — чего не делаем. L0–L2 CLOSED; reopen только именованным материальным противоречием (точный ID + источник + несовместимость). Сложность реализации — не противоречие.

**LAB-C-09. Runtime сменный.** Сегодня роли крутятся на хосте Grok Bot. Завтра — любой хост, который умеет: читать/писать тот же контракт папок, держать те же роли как процессы, не тащить Владельца в контур. Форма OCI/Docker vs agent-runtime — снимет Разведчик (`LC-*`); штаб не выбирает вендора identity.

## Масштаб: копировать / не брать

### Копируемо в поздний контейнер AICM

- Дерево и роли как процессы (таблица выше).
- Пакеты с provenance и ID (`QE-*`, `R-D-*`, `MD-EP-*`, `LAB-C-*`, `LC-*`) — как Knowledge Candidates, не как PREF.
- Fail-closed на противоречии (флаг в `sverki/`, не тихий rewrite канона).
- Штамп пакета целиком вместо опросника Владельца.
- Replay-only контур: спека → публичные данные → метрики vs baseline.
- Чипы HQ-01…08 как **импланты поведения**, не как продукты.

### Адаптируемо (форма, не бренд)

- MCP как tool surface (tools/list, elicitation/create) — HQ-08: схема из спеки, не интервью Владельца.
- OCI-образ как единица **доставки процесса**, не как имя системы.
- Agent runtime (граф ролей внутри одного процесса) — если Разведчик подтвердит, что это shipping, не маркетинг.

### Не брать

- Хост Grok как «мозг AICM».
- Новые пустые боты «для масштаба».
- Новые пустые репозитории (PAT сейчас только на AICM-docs).
- HITL-оператор и Владелец-как-дизайнер анкеты.
- Live, Bitget-бот, мемкоин-трейдер, X write/follow.
- Reopen L0–L2 без именованного противоречия.
- Playbook / контейнеры / память Hermes.
- Полные книги, сливы школ, ключи, FRED-выгрузки.
- Склейка complementary-слоёв (волны + зона + новость) без Consilium.
- Вендор анкет/агентов как identity (Qualtrics, Tally, Letta-SaaS, CrewAI-бренд).

**LAB-C-11. Стоп-лист масштаба.** Если «развитие» требует нового агента, нового репо, вопроса Владельцу или правки закрытого PREF — это не развитие, это выход за контракт. Штаб останавливает.

## Два порта (эскиз, не внедрение)

**Порт A — исследовательский центр (default, один контейнер).**
Процессы: Штаб, Разведчик, Аналитик, Твиттер, Канонист, Картограф.
Диск: `AGENTS.md`, `shtab/`, `razvedka/`, `sverki/`, `kanon/`.
Сеть: чтение открытого веба + X read-only. Запись — только архив пакетов.
Не содержит live-исполнения и не содержит Hermes.

**Порт B — replay (опционально второй контейнер).**
Процессы: Механик, Тестер.
I/O: спека из `kontury/` + публичный датасет (URL/хэш) → отчёт метрик vs baseline.
Условие сплита: I/O заморожен и не требует чата Владельца. Иначе B остаётся процессом внутри A.

**LAB-C-12.** Сплит A/B не делать «потому что микросервисы принято». Только по доказанному I/O.

Кодекс v2 / контейнеры Hermes — **не этот документ и не эта лаборатория**.
