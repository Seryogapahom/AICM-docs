# План цикла 2 — переработка

Статус: план штаба. Не канон. Не внедрение Hermes. Не live.
Дата: 2026-08-30.

Владелец открыл цикл: накопленного достаточно, чтобы **перерабатывать** — спеки, исторические прогоны, ежедневный сбор. Параллельно главному механизму, пока не согласовано. Позже можно клонировать контур из этого репозитория.

## Два потока каждый будний день (10:00)

**A. Сбор.** Разведчик: открытый код, данные, стратегии, что устарело. X отложен. Срез ради среза — нет. Штаб архивирует.

**B. Переработка.** Один инкремент: либо спека контура (Механик), либо прогон по уже принятой спеке (Тестер). Не все стратегии сразу.

Владельцу — только External Enabler или материальный итог (спека, отчёт с метриками, блокер). Не звать ревьюить черновики.

## Очередь контуров

| ID | Что | Успех | Стоп |
|---|---|---|---|
| K-0 | Каркас replay без стратегии | Публичные свечи читаются, считаются метрики, есть baseline buy&hold и no-trade | Нет данных / выдуманные числа |
| K-1 | Nautilus replay-only | Гипотеза отличия от неудачной попытки в основном проекте записана *до* кода; прогон против K-0 baseline | Гипотеза пустая; live; повтор той же попытки |
| K-1b | Запасной движок | Только если K-1 пустой. LEAN или более тонкий из пакета OSS | Freqtrade/Jesse/Hummingbot как дом live |
| S-* | Стратегия из архива | Одна узкая формулировка, один слой, проверяемые правила входа/выхода | Гибрид слоёв; «весь Андреев» |

Первый лабораторный датасет: Binance Vision `BTCUSDT` 1h (публичные zip). Это проверка каркаса, **не** замена Bitget и не архитектурный контур Hermes.

## Nautilus — правило

В основном проекте уже пробовали, нужных результатов не дал.
Лаборатория не ставит Nautilus домом. K-1 без записанной гипотезы отличия — не стартовать.

Гипотезу писать из открытых свойств движка и наших ограничений (replay-only, каталог данных, не live, не Bitget-бот). Логов той попытки у лаборатории нет — не выдумывать, почему именно она упала.

## Стратегии (после K-0)

Не гибрид. Очередь узких формулировок штаб назовёт по одной, когда каркас умеет считать. Кандидаты лежат в `razvedka/`, сверки в `sverki/`. Consilium здесь не строим.

## Где лежит код прогона

Прогон идёт на компьютере лаборатории. В этот репозиторий — спека и отчёт (числа только из прогона). Реализацию Hermes сюда не класть. Отдельный кодовый репозиторий — только по прямому запросу Владельца и после расширения токена.
