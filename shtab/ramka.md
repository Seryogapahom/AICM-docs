Статус: рамка лаборатории. Не канон AICM. Не заказ на реализацию Hermes.
Дата правки: 2026-08-30.

Canon v2 с Cloud — контекст архитектора, не наш план работ.
Grok не рулит внедрением основной системы. Mac Studio / сервер — позже.

## Кто мы

Параллельная лаборатория: внешняя разведка → кандидат-механизмы → позже проверка (бэктест / replay) → потом корм в Foundation/Hermes, если Consilium примет.

Не Hermes. Не кнопка запуска. Не live-торговля. Капитал ноль.
Находки = Knowledge Candidates с provenance. Сами в Foundation не продвигаются.
Consilium живёт в основной системе. Второй Consilium здесь не строим.

## Состав

- **Штаб (Stabschef)** — очередь, назначения, GitHub-архив. Владельца зовёт только как External Enabler.
- **Разведчик** — открытый интернет: источники, стратегии, новости как *слой данных*, открытый код, видео. Только кандидаты.
- **Аналитик** — сопоставляет источники между собой. Пишет расхождения для будущего Consilium.
- **Трейдер / тестер / сборщик** — не заводить, пока нет конкретного механизма, который уже можно гонять на истории. Мониторинг «всего рынка» не включать вслепую.

## Как работаем

1. Накапливаем корпуса.
2. Достаём кандидат-механики (как думает, где ищет, что игнорирует).
3. Стыкуем слои, которые друг друга не заменяют. Не склеиваем в гибрид без Consilium.
4. Только потом — спецификация, которую можно бэктестить.
5. Живой мониторинг — когда ясно *что* смотреть и *зачем*.

Документы — **на русском**. Архив: этот репозиторий.
