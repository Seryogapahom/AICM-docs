## Кто мы

Параллельная лаборатория к главному механизму (Hermes). Пока **не согласовано** с ним: копим, специфицируем, гоняем на истории. Позже контур можно клонировать / подключить, если он эффективен.

Цепочка: внешняя разведка → кандидат-механизмы → контур (спека) → replay/бэктест → корм в Foundation/Hermes, если Consilium примет.

Не Hermes. Не кнопка запуска. Не live-торговля. Капитал ноль.
Находки = Knowledge Candidates с provenance. Сами в Foundation не продвигаются.
Consilium живёт в основной системе. Второй Consilium здесь не строим.

## Состав

- **Штаб (Stabschef)** — очередь, назначения, GitHub-архив, суточный цикл. Владельца зовёт только как External Enabler.
- **Разведчик** — открытый интернет: источники, стратегии, новости как *слой данных*, открытый код. Только кандидаты.
- **Аналитик** — сопоставляет источники между собой. Пишет расхождения для будущего Consilium. Не гибридизирует.
- **Твиттер** — новинки с X, когда сессия будет. Сейчас idle: X отложен Владельцем.
- **Механик** — спецификации контуров (как работает, какие данные, метрики). Один контур за brief.
- **Тестер** — исторический replay по принятой спеке. Отчёт метрик против baseline. Не live.
- **Трейдер** — нет. Живых сделок из лаборатории нет.

## Как работаем (цикл 2)

Каждый будний день: сбор **и** переработка. Один инкремент контура или один прогон, не «все стратегии сразу».

1. Накапливаем корпуса (не останавливаем).
2. Достаём кандидат-механики.
3. Стыкуем слои, которые друг друга не заменяют. Не склеиваем в гибрид без Consilium.
4. Пишем спецификацию контура, которую можно бэктестить.
5. Гоняем на публичной истории против baseline. Нет числа без прогона.
6. Живой мониторинг — когда ясно *что* смотреть и *зачем*. Не сейчас.

Документы — **на русском**. Архив: этот репозиторий. Код основной системы сюда не кладём; прогоны лаборатории — отчёт в `kontury/`.
