# Цели и очередь лаборатории

Статус: очередь штаба. Не канон. Не план внедрения Hermes.
Дата: 2026-08-30. Обновляет только Штаб.

## Цель лаборатории (длинная)

Накопить внешние корпуса и кандидат-механики так, чтобы позже Hermes/Foundation могли **клонировать этот репозиторий** и взять готовые пакеты с provenance — без серых PDF, без сливов школы, без ключей.

Проверка на истории — следующий класс работ, не текущий. Live — ещё позже и только на именованный объект слежки.

## Очередь (сейчас)

1. **Держать склад читаемым.** Каждый новый пакет — файл + строка в индексе. Штаб архивирует, не «все пишут куда попало».
2. **Не стартовать** трейдера, тестера, live-мониторинг, новостного бота.
3. **Не склеивать** слой Андреева и слой Радченко. Две отдельные проверки на истории — когда дойдём до спеки, не раньше.
4. **Следующий корпус — только по brief штаба** (пример: бесплатные ролики Радченко про US, если Владелец даст URL; или другой complementary-источник). Не открытый поиск «всего рынка».
5. **Бэктест-спека** — после того как штаб назовёт *один* кандидат на проверку. Кандидаты на потом, не сейчас:
   - replay крипты без новостного календаря (слой Андреева);
   - детектор «новость или 10% print уже в цене» + сектор (слой Радченко).
6. **FRED / BLS / платные ленты** — не внедрять. FRED ToS 2024 блокирует AI+архив.

## Что просим у Владельца (External Enabler)

Только если без этого нельзя: URL, логин на легальный источник, оплата, расширение прав GitHub-токена (сейчас токен только на `AICM-docs`). Новые репозитории не нужны, пока этот один не станет тесен.
