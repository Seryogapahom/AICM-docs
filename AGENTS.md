Читать **до** любой записи в этот репозиторий. Язык — русский.

Репозиторий: приватный `Seryogapahom/AICM-docs`.  
Клон / перегрузка: это и есть склад кандидатов, не боевой AICM.

## Роли

| Роль | Пишет сюда | Не пишет |
|---|---|---|
| **Штаб (Stabschef)** | Дерево, `shtab/`, README, AGENTS, решение что архивировать | Реализацию Hermes |
| **Разведчик** | Новые корпуса и механики в `razvedka/` | Сверки «кто прав», канон, live-боты |
| **Аналитик** | Сопоставления в `sverki/` | Перезапись чужих пакетов, слияние v1/v2/v3 |
| **Твиттер** | Новинки в `razvedka/novinki/` | Канон, live, дубли пакетов Андреева/Радченко |
| **Трейдер / тестер / сборщик** | Пока нет роли. Не заводить папку под них | — |
| **Владелец** | Ничего. External Enabler: логин, оплата, ссылка, которой нет у агентов | Проектирование, ревью, кнопка запуска |

## Куда класть

1. Новый **корпус или механика** → `razvedka/YYYY-MM-DD-<тема>.md` + строка в `razvedka/README.md`.
1a. **Новинка** (X, инструмент, новость как сигнал) → `razvedka/novinki/YYYY-MM-DD-<тема>.md` + строка в `razvedka/novinki/README.md`. Не сваливать в один файл с механикой трейдера.
2. **Сверка** двух уже снятых слоёв → `sverki/YYYY-MM-DD-<a>-vs-<b>.md` + строка в `sverki/README.md`. Не класть сверку внутрь пакета разведки, если это сопоставление.
3. Смена рамки лаборатории → только Штаб, файл `shtab/ramka.md`.
4. Смена целей/очереди → только Штаб, файл `shtab/celi.md`.
5. Карты расхождений **не сливать**. v1, v2, v3 — отдельные файлы навсегда.

Имя файла: дата съёма, латинский слаг, без пробелов. Заголовок внутри — по-русски.

## Обязательный шапочный блок в каждом пакете

```
Статус: Knowledge Candidate. Не Foundation. Не канон AICM.
Дата: YYYY-MM-DD
Источник: URL или «открытый HTML» + дата доступа
Provenance: что смотрели / чего не копировали
```

Без источника файл не принимать в архив.

## Статусы (не путать)

| Метка | Значит |
|---|---|
| Knowledge Candidate | Можно копить и сверять. Не закон |
| Инкремент | Добавка к уже снятому пакету, не новый канон |
| Consilium-кандидат | Сверка для *будущего* Consilium основной системы |
| Канон AICM | Сюда **не ставить**. Канон живёт в Hermes |

Находка сама в Foundation не продвигается.

## Запрещено класть

- Полную книгу, главу verbatim, слив школы, VIP, закрытый PDF
- Ключи, токены, `.env`, session, пароли
- Код/схемы памяти основной системы, контейнеры, playbook внедрения Hermes
- «Серый» источник «потому что полезно»
- Полные стенограммы эфиров (только механика + provenance URL)
- Черновики `_draft-*` — сырьё штаба, не архив

FRED API: ToS (июнь 2024) запрещает AI-тренировку и архив содержимого API. Не складывать выгрузки FRED.

## Как писать

- Русский. Идентификаторы файлов — латиница.
- Короткие цитаты с provenance, не простыня.
- Число только если оно есть на открытой странице или в уже снятом файле. Нет числа — написать «не найдено», не выдумывать корреляции.
- Даты слоёв не склеивать (вебинар 2024 ≠ LIVE 2026 ≠ другой гость).
- Два complementary-слоя **не гибридизировать** («волны + новость» как одна механика) без Consilium.

## Как читать при клоне / перегрузке

1. `README.md` — что это за склад.
2. `shtab/celi.md` — что штаб считает очередью **сейчас**.
3. `shtab/ramka.md` — чего лаборатория не делает.
4. `razvedka/README.md` — индекс корпусов.
5. `sverki/README.md` — какие напряжения уже названы.
6. Не тащить L0–L2 сюда «на всякий случай». Закрытое закрыто.

## Git

- Ветка `main`. Коммиты атомарные: один пакет или одна сверка, плюс правка индекса.
- Сообщения коммитов по-русски, с датой если это пакет.
- Не force-push. Не создавать соседние репозитории без прямого запроса Владельца и без прав токена.
- Issues — очередь видимая человеку; живая очередь штаба всё равно в `shtab/celi.md`.

## Конфликт с каноном Cloud

Canon v2 / Cloud — контекст архитектора, не план работ этой лаборатории. Сложность реализации Hermes — не повод открывать L0–L2 и не повод писать сюда «как внедрять».
