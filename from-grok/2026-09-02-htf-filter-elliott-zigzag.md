Вопрос пакета: что публичные HTML **считают направлением старшего ТФ**, когда HTF — *фильтр* к коррекции/zigzag (не учебник импульса).

## HTF-01 — ElliottWaveSpot: три ТФ, zigzag = внутренность HTF-счёта

- **Источник:** ElliottWaveSpot, «How to use multiple time frames in Elliott Wave trading?» (2025-08-28)  
- **URL:** https://elliottwavespot.substack.com/p/how-to-use-multiple-time-frames-in  
- **Доступ:** 2026-09-02  
- **Что считают направлением старшего ТФ:** не close 4h, не EMA, не трендлайн. **Метка волны большей степени на Overall analysis TF** (пример: triangle wave `(C)` of `[4]` на **1W**; альтернативная иерархия: Overall = **1D/2D**). Направление = какой старший сценарий уже принят (здесь: `(C)` как zigzag, не triple zigzag).  
- **Как фильтруют коррекцию/zigzag:** Trading TF подтверждает «possible zigzag unfolding» как **внутренний счёт** HTF-outlook; ждут `[i]` и `[ii]` of A внутри `(C)`; unicorns (triple zigzag, wave E triangle) **не берут**. Не «торговать ABC против HTF».  
- **1h vs 4h:** названы. Trading TF = **1H–4H (4H preferred)**; Entry = **15–45m**. «Most EW love to use **1H more than 4H**» — из-за ясности PA, не потому что 1H = HTF для M15. 4H в одном примере — **entry** к 1D-торговле, не HTF к 1h-zigzag.  
- **Вердикт:** адаптируемо (иерархия ТФ). Не брать как жёсткую пару «1h zigzag / 4h filter».

## HTF-02 — StockPathshala: Daily = тренд, 4h = ABC, 1h = вход

- **Источник:** StockPathshala, «Which Time Frame Is Best For Elliott Wave» (2026-03-19)  
- **URL:** https://stockpathshala.com/which-time-frame-is-best-for-elliott-wave/  
- **Доступ:** 2026-09-02  
- **Что считают направлением старшего ТФ:** **major trend на Weekly/Daily** (Primary). Intermediate ≈ **4h swing waves**. Не close последней 4h-свечи, не наклон EMA. Объект — **волна старшей степени на старшем графике**. Правило конфликта: «The higher timeframe always has priority».  
- **Как фильтруют:** LTF-волны обязаны **вкладываться** в HTF, не противоречить. Пример: Daily = Wave 3 вверх → **4h = ABC pullback** внутри 3 → 1h = малая пятёрка продолжения. Intraday: 4h Wave 4 → **шорты ралли, пока не началась 5**. Вход на 4h/1h только если **align with HTF**.  
- **1h vs 4h:** названы явно. **4h = средний ТФ** (структура/ABC), **1h или 15m = нижний** (вход). Не «4h как HTF к 1h-zigzag» как единственная схема: для свинга HTF = Daily, 4h = коррекция внутри. Day trader: 4h + 15m.  
- **Вердикт:** адаптируемо как карта ролей ТФ. Не брать индийские Nifty/expiry-рецепты.

## HTF-03 — EWF Tools 2026: HTF-тренд выравнивает LTF-zigzag (Wave 2)

- **Источник:** Elliott Wave Forecast, «Top Tools… Elliott Wave Analysis in 2026» (2026-05-16)  
- **URL:** https://elliottwave-forecast.com/elliottwave/elliott-wave-tools-and-indicators/  
- **Доступ:** 2026-09-02  
- **Что считают направлением старшего ТФ:** **weekly trend direction + daily structure + «higher timeframe Elliott Wave structure»**. Не close 4h, не EMA. Ichimoku на странице — «higher timeframe bias / filter corrective noise», отдельно от MTF-блока.  
- **Как фильтруют:** «best blue box setups occur when **higher timeframe trend direction aligns with lower timeframe corrective structures**». Пример BTC **1H**: bullish Wave 1 → Wave 2 как **zigzag** → покупка отката в blue box **по направлению HTF**, не торговля самого зигзага против HTF. MTF «helps avoid counter-trend trades».  
- **1h vs 4h:** **пара 1h/4h не названа.** 1H — графики исполнения (DAX, EURUSD, BTC). HTF в тексте = **weekly / daily / intraday execution**.  
- **Вердикт:** адаптируемо (align LTF-коррекции с HTF-импульсом). Не брать proprietary Blue Box / live EWF.

## HTF-04 — Audacity Capital: HTF = направление свингов на ТФ *выше торгового*

- **Источник:** AudaCity Capital Research, «Elliott Wave Theory: How to Identify and Trade Wave Patterns» (обновл. 2026-08-20)  
- **URL:** https://audacity.capital/trading-guides/elliott-wave-theory/  
- **Доступ:** 2026-09-02  
- **Что считают направлением старшего ТФ:** **направление ясных swing high/low на таймфрейме выше торгового.** «The direction of this trend is the direction that the motive wave should take.» Счёт **обязан стартовать с пунктов на next higher TF**. Объект = **HTF-свинги / степень**, не close, не EMA, не 4h-линия.  
- **Как фильтруют:** zigzag = sharp A-B-C **против** этого HTF-тренда (5-3-5). После ABC смотрят **возобновление старшего тренда**, «wait for price confirmation rather than acting solely because a C label has been drawn». Ошибка №4: count без HTF-якоря — fragile.  
- **1h vs 4h:** **не названы.** Есть «intraday» vs HTF; fractal «any timeframe», но intraday шумнее → якорь на HTF.  
- **Вердикт:** копируемо как определение объекта HTF (свинги старшего графика). Не брать как готовую систему входа.

## HTF-05 — Financial Tech Wiz: одна степень вверх = контекст; zigzag типичен в wave 2

- **Источник:** Mike Toney-Hoffman, «Elliott Wave Theory: How to Count and Trade Waves» (обновл. 2026-08-01)  
- **URL:** https://www.financialtechwiz.com/post/elliott-wave-theory/  
- **Доступ:** 2026-09-02  
- **Что считают направлением старшего ТФ:** **волна на одну степень выше** («which direction the larger trend is pushing»). Для свинга: primary = **Daily**, контекст = **Weekly**, вход = **4-hour or hourly внутрь wave 2 или wave 4**. Не close 4h-свечи.  
- **Как фильтруют:** zigzag = острый ABC, «common in **wave 2**», ощущается как разворот. Торгуют **не сам зигзаг против HTF**, а **вход в wave 3 после wave 2** (стоп под low 2). Hourly 5-wave может быть одной волной Daily.  
- **1h vs 4h:** оба названы как **entry TF** к Daily, не как «4h = HTF для 1h-zigzag». «Counts below 15-minute tend to be noise».  
- **Вердикт:** адаптируемо (3 степени: trade / +1 / −1). Не брать журнал/промо приложения.

## Общее / где расходятся (без гибрида)

**Общее:** ни один из пяти не считает HTF «close последней 4h» или «наклон 4h EMA». Объект — **волна/свинги большей степени на графике выше**. Zigzag на младшем ТФ фильтруют как **коррекцию внутри HTF-импульса** (Wave 2 / ABC pullback / blue-box отката), а не как самостоятельный контртренд.

**Расходятся (не склеивать):**
- **HTF-01:** 4H может быть *торговым* или *входным* ТФ — не фиксированный HTF к 1h.  
- **HTF-02:** 4h = *средний* (ABC), HTF = Daily/Weekly; 1h = вход.  
- **HTF-03:** HTF = weekly/daily EW-структура; 1h/4h как пара не сказано.  
- **HTF-04:** формула «ТФ выше торгового», без имён 1h/4h.  
- **HTF-05:** 4h **или** 1h = timing внутрь Daily wave 2/4.
