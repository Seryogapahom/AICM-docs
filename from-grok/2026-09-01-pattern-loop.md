# Ежедневный контур паттернов (для Foundation, не канон)

```
Статус: Knowledge Candidate / живой runbook лаборатории. Не Foundation. Не PREF AICM. Не канон.
Дата: 2026-09-01
Источник: предпочтение Владельца в чате штаба, 2026-09-01 ~22:15 Europe/Zurich
```

Лаборатория Grok продолжает внешнюю разведку. Обменник (`from-*`) — дверь, не отмена работы.

Цель контура: каждый будний день снять **пять** правил/паттернов (уклон: Эллиотт — коррекции, треугольники, зигзаг, ABC, флаги как отдельный слой если не волны, объём как подтверждение), описать по-русски, операционализировать, прогнать на истории, зафиксировать, спросить «схема лучше или хуже». Пакеты — сырьё для будущей книги/Foundation, не закон AICM.

## Роли (новые боты не плодить без нужды)

| Кто | Что делает |
|---|---|
| Разведчик + Твиттер | Сбор кандидатов. X только чтение `@acapitalmanager`. **Не follow, не посты.** |
| Штаб | Выбор пяти, архив в `from-grok/patterns/`, brief Механику/Тестеру |
| Механик | Один контур: if/then, бары, метрики распознавания. Не гибрид слоёв |
| Тестер | Replay на публичных данных (старт: каталог K-0 BTCUSDT 1h Binance Vision). Не live |
| Аналитик | Правило vs факт прогона. Расхождение отдельно, не «подкрутить пока 70%» |
| Эволюционист | Один вопрос к схеме: распознавание лучше/хуже; предложение штабу. Не меняет закрытые L0–L2 |

## День (будни, внутри цикла 10:00)

1. **Сбор.** Пять кандидатов из открытых источников (HTML, публичные видео, X search). Не школа, не серый PDF, не полный текст закрытой книги. Не повторять уже снятый пакет без инкремента (другой источник / другая операционализация).
2. **Карточка** на каждый (`from-grok/patterns/YYYY-MM-DD-pN.md`): имя; слой (EWP / объём / прочий — не склеивать); дословное правило + расчёт; подтверждение продолжения vs разворот; какие бары/индикаторы; provenance URL; статус кандидат.
3. **Прогон.** Из пяти штаб берёт те, у кого if/then уже заморожены. Остальные остаются карточками. Прогон = исторические бары, метрики vs правило, не подбор «пока красиво». Win rate **60–70% — ориентир диагностики**, не обещание P&L. При n<20 — `INSUFFICIENT_SAMPLE`, не FAIL и не «механизм готов».
4. **Сверка.** Правило написано так, рынок выглядит иначе — это находка, не повод менять правило книги. Меняется только детектор (порог, бар, фильтр), и это пишет Эволюционист как предложение.
5. **Отчёт дня** в `from-grok/patterns/YYYY-MM-DD-dnevnik.md`: пять имён, сколько прогнали, WR/n если есть, лучше/хуже схема. Владельцу — коротко, только материальный итог. Пустой день без сюрприза — по циклу можно молчать.

## Эволюция схемы (не эволюция канона)

Раз в день Эволюционист отвечает: детектор распознал правило лучше или хуже, чем вчера (на том же ряде, если ряд заморожен). Штаб принимает одну правку схемы или отклоняет. Правило из открытого учебника не переписывается «чтобы WR вырос».

## Первый задел (не пять прогонов в ночь задания)

Очередь на ближайший цикл, из уже лежащего корпуса, без склейки:

1. зигзаг A-B-C (EWP, дайджест Frost/Prechter + открытый HTML)
2. треугольник (отдельный слой TE уже снят — операционализация, не повтор каталога)
3. плоская коррекция (flat)
4. объём как подтверждение, не как вход (слой Геворкяна не клеить с EWP)
5. флаг/вымпел как **не-EWP** паттерн (отдельный слой)

Штаб не обещает 60–70% на первом прогоне. Обещает карточки, замороженный if/then, n и честный статус.
