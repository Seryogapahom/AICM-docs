## Имя

Плоская коррекция Flat A-B-C (3-3-5), включая expanded как частый вид.

## Слой

**EWP.** Sideways correction. В 4-й часто, во 2-й редко (guideline). Не склеивать с TE-треугольником и объёмом.

## Дословное правило + расчёт

- Flat = A-B-C, счёт **3-3-5**; regular / expanded (часто) / running (редко — не ставить рано).
- Expanded: B и/или C выходят за начало/конец A; C часто **1.618×A**.
- Отличие от зигзага: B **глубокая** (около полного отката A или beyond), не «острый» 50–61.8 только.

Лабораторная операционализация (заморожена до прогона):

1. Пивоты фрактал L=3; те же 4-пивотные ABC-формы, что у ZZ, но порог B другой.
2. **B/A ≥ 0.90** (глубокая B; expanded часто >1.0).
3. C достигает/переходит конец A (`FLAT_C_BEYOND`).
4. Исход: после C ожидать resume против C (как у коррекции), target/stop 0.382/0.236 × max(|C|,|A|), H=48.

Пересечение с P1 по зоне B∈[0.90,0.886] пустое; B≥0.90 уходит в flat. Сигналы двух карточек считаются **отдельно** (разные слои/правила), без дедупа.

## Подтверждение продолжения vs разворот

После C flat — ожидание возобновления старшего хода (против C). Уход цены дальше по C до диагностического стопа = схема «коррекция не завершена / счёт снят» на этом окне.

## if/then (ЗАМОРОЖЕН)

```
IF 4 чередующихся пивота L=3 (bull L-H-L-H / bear H-L-H-L)
   AND B/A ≥ 0.90
   AND C достигает или переходит конец A
THEN отметить flat_ABC на confirm C
   AND диагностика: ожидать ход ПРОТИВ C
       height = max(|A|,|C|); target=0.382×height; stop=0.236×height; H=48
ELSE не сигнал
```
