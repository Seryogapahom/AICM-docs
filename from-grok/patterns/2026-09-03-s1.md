## Определение «один и тот же C» (ЗАМОРОЖЕНО до WR)

Ключ конфликта = пара `(confirm_bar_C, c_side)`:
- `confirm_bar_C` — индекс бара подтверждения пивота C (как entry в P1/P3: confirm = pivot_bar + L, L=3);
- `c_side` — `up_C` для bull_zz / bull_flat (L-H-L-H), либо `down_C` для bear_zz / bear_flat (H-L-H-L).

Не смешиваем up_C с down_C. Не используем «только pivot bar без confirm» — confirm уже в детекторах дня 1.

## Идеальные центры B/A (ЗАМОРОЖЕНЫ до WR)

| Паттерн | Идеал B/A | Почему |
|---|---|---|
| Zigzag (P1) | **0.618** | classic 61.8%; середина коридора [0.382, 0.886] |
| Flat (P3) | **1.0** | глубокий B (deep B ≈ 100% A) |

Расстояние: `dist = abs(B/A − ideal)`.

## if/then (ЗАМОРОЖЕН до прогона)

```
IF существует сигнал P1 (zigzag) и сигнал P3 (flat)
   с одинаковым ключом (confirm_bar_C, c_side)
THEN
   d_zz   = abs(br_zz   − 0.618)
   d_flat = abs(br_flat − 1.0)
   IF d_zz < d_flat THEN оставить ZZ, выбросить flat
   ELSE IF d_flat < d_zz THEN оставить flat, выбросить ZZ
   ELSE (ничья) оставить ZZ, выбросить flat   # tie-break: ZZ
ELSE каждый сигнал живёт как соло своего слоя

Отчётные множества:
  (a) P1 solo unchanged
  (b) P3 solo unchanged
  (c) P1 after dropping conflicts
  (d) P3 after dropping conflicts
  (e) union of survivors (каждый ключ C не чаще одного раза)
```

Не D-1. Не live. После WR пороги S1/P1/P3 не тюнить.
