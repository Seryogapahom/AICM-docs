## Определения канала (checkable)

На импульсном баре P4 `i` (тот, что дал CONFIRM_CONTINUE на pullback `j`):

```
range_high = max(high[i-L .. i-1])
range_low  = min(low[i-L .. i-1])
range      = range_high − range_low
если range ≤ 0 или баров < L → нет V1 (недостаточно истории)
pos_i = (close[i] − range_low) / range

LOC_LOW  := pos_i ≤ α
LOC_HIGH := pos_i ≥ (1 − α)
LOC_MID  := иначе

FIX_ABOVE := ∃ m ∈ {i .. i+3}: close[m] > range_high
FIX_BELOW := ∃ m ∈ {i .. i+3}: close[m] < range_low
```

`FIX_*` — операционализация слов пакета «закрепились / проторговка **выше** уровня» (зеркало вниз). Не фибо, не теневая сетка.

## STRENGTHEN vs SKIP (ядро дыры #11)

P4 по-прежнему только CONFIRM, не ордер. V1 помечает CONFIRM:

**Для direction d = +1** (усиление long / resume вверх):

- **STRENGTHEN** если P4 `CONFIRM_CONTINUE(direction=+1)` и (`LOC_LOW` **или** (`LOC_HIGH` и `FIX_ABOVE`)).
- **SKIP** если CONFIRM +1 и `LOC_HIGH` без `FIX_ABOVE` (верх диапазона без закрепления — пакет: не покупает).
- **SKIP** если CONFIRM +1 и `LOC_MID` (пакет про низ/верх; середину не объявляем «размером»).

**Для direction d = −1** (зеркало):

- **STRENGTHEN** если P4 `CONFIRM_CONTINUE(direction=−1)` и (`LOC_HIGH` **или** (`LOC_LOW` и `FIX_BELOW`)).
- **SKIP** если CONFIRM −1 и `LOC_LOW` без `FIX_BELOW`.
- **SKIP** если CONFIRM −1 и `LOC_MID`.

Иначе (нет P4) — нет усиления.

## if/then (ЗАМОРОЖЕН до прогона)

```
IF сработал P1 zigzag_ABC на 1h баре t
AND direction_resume ∈ {+1, −1}
AND существует окно k ∈ {t .. t+3}:
      на этом окне выполнен P4 CONFIRM_CONTINUE
      с direction = direction_resume
      (импульс i и pullback j по правилам P4; j = бар confirm P4)
AND для этого CONFIRM статус = STRENGTHEN по правилам V1 выше
THEN сигнал V1 на баре j (confirm P4), не на t
   диагностика как P1: target = 0.382×|C|, stop = 0.236×|C|, H=48 от j
   один P1 → не более одного V1 (первый STRENGTHEN в окне)
ELSE нет V1
   (P1-соло и C1-соло при этом не становятся входом)
NEVER: открывать вход только по P4/V1 без P1; тюнить L/α/SMA после WR;
       переписывать P4; клеить учебник EWP+объём в одну теорию
```

Отличие от C1: C1 принимает любой P4 в сторону resume; V1 принимает только **STRENGTHEN**. P4 файл не редактировать.
