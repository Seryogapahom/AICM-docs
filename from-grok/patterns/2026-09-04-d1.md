# D1 — P1 AND daily mid-range ≥0.25

Статус: Knowledge Candidate. Не Foundation. Не канон.
Дата заморозки: 2026-09-04
Слой: схема P1 + положение close на Daily. Не S2 (знак 5d). Не N1 (4h mid-range). Не C3 (SMA20).

## Зачем

N1 на 4h не лифт (40.25%). Параллель на Daily: отсечь пилу старшего ТФ без знака свечи и без SMA.

## if/then (ЗАМОРОЖЕН до прогона)

```
IF сработал P1 zigzag_ABC на 1h баре t
AND есть 20 полностью закрытых UTC-дней с датой < даты t
AND range = max(high) − min(low) по этим 20 дневным барам
AND mid = (max(high) + min(low)) / 2
AND range > 0
AND abs(close_D − mid) / range ≥ τ
   τ = 0.25 (заморожен; параллель N1, не подкрутка N1)
THEN сигнал D1 на баре t
   диагностика как P1: target 0.382×|C|, stop 0.236×|C|, H=48
ELSE нет D1
```

Пороги P1 и τ **не** крутить после WR. C1–C3/S1/H1/S2/I1/W1/N1 не ретро-tune. Не live.

## Метрики

n_D1, WR, сколько P1 отрезал, expectancy, vs P1 40.60%. n<20 → INSUFFICIENT_SAMPLE.
