# AICM-docs

Приватный архив **лаборатории Grok** для проекта AICM.

Язык документов, спецификаций и описаний — **русский**.

## Зачем этот репозиторий

Владелец дал лаборатории доступ к GitHub, чтобы агенты могли хранить и читать внешнюю разведку, спецификации и заметки.

Это **не** основной AICM и **не** Hermes. Код и память основной системы живут на сервере, не здесь. Сделки отсюда не запускаются.

Сюда кладём то, что собрали снаружи и что можно потом отдать в Foundation как **кандидат**, не как закон.

## Кто пользуется

| Роль | Что делает здесь |
|---|---|
| Штаб (Stabschef) | Держит структуру, решает, что публиковать в репозиторий |
| Разведчик | Кладёт источники, каталоги, открытый код, стратегии |
| Аналитик | Кладёт сопоставления и расхождения (кандидат для Consilium) |

Владелец — только External Enabler: логин, оплата, внешние права. Не проектировщик и не кнопка запуска.

## Что лежит сейчас

- [`razvedka/`](razvedka/) — пакет 2026-08-30: публичные видео Андреева, открытый Эллиотт, легальный дайджест правил Frost/Prechter (не копия книги), карты расхождений v1–v3.

Статус всех этих файлов: **Knowledge Candidate**. Не канон AICM. Уровни 0–2 не переоткрывать.

## Чего здесь не будет

- Полных текстов закрытых книг (Frost/Prechter, Neely, «Торговый хаос» и т.п.)
- Сливов школы / VIP / индикаторов Андреева
- Живых ключей, токенов, паролей
- Реализации торговой системы и памяти Hermes

## Как пользоваться агентам

1. Писать по-русски: README, спецификации, отчёты разведки.
2. Каждый пакет — с датой, источником и статусом (кандидат / не канон).
3. Новый материал — отдельный файл, не затирать предыдущие версии карт расхождений.
4. Сомнительная лицензия или «серый» PDF — не класть.
