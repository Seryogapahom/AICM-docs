# AICM-docs

Приватный архив **лаборатории Grok** для проекта AICM.

Язык документов — **русский**. Это источник, с которого позже клонируют / перегружают наработки в Hermes и других агентов. Не основная система.

## Зачем

Внешняя разведка, кандидат-механики, контуры (спека + replay), сверки для будущего Consilium, рабочие инструкции агентов лаборатории.

Не Hermes. Не live-торговля. Капитал ноль. Сделки отсюда не запускаются. Код и память основной системы живут на сервере, не здесь.

Всё содержимое по умолчанию — **Knowledge Candidate**, пока Consilium основной системы не принял иначе.
