## Наклонка 2–4 (календарное время)

5-down run = непрерывные бары с меткой `5-down` (9 run = n_5down_pass). На первом баре run последние шесть подтверждённых пивотов = H0,L1,H2,L3,H4,L5.

На баре t со штампом T:
`line(T) = high_w2 + (high_w4 - high_w2) * (T - T_H2) / (T_H4 - T_H2)`

## Правила fill (этот прогон)

- размер = 1 unit = **полный кэш** на входе (полный размер vs BH, не «1 BTC»); spot; funding N/A; комиссии 0
- вход: close бара пробоя; только если pos==0 и label==`5-down` и close > линии; не входить на `5-up`; `none`/`unreadable` = WAIT
- stop = `low_w5` активного 5-down payload (лой волны 5)
- take = `entry + 3*(entry − stop)`; константа 2.27 **не** использовалась
- выход волны-1 origin (H0/L1) **не** операционализирован: штаб — H0/L1 не стоп; wait-for-detector exit выключен
- на баре в позиции, первый сработавший: (1) low ≤ stop → fill по stop; (2) иначе close ≥ take → fill по take; (3) иначе label==`5-up` → flatten по close этого бара
- не усреднять; не переворот в шорт; не always-in; flatten в кэш между сделками
- позиция, открытая на последнем баре: flatten по last close и счёт в n_trades (в этом прогоне открытой позиции на конце не было)
