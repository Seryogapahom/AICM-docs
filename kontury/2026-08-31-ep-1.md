## 5. Checkable gates

Идентификаторы латиницей. Overlay **не** меняет if/then S-1. Гейт = булево на уже снятом филле / на серии. «Быть уверенным» гейтом не является (MD-EP пакет §1).

Новых числовых констант нет: `size_plan = 1 unit` уже в S-1 §5.2; `N ≥ 20` — упражнение Elearnmarkets / `R-D-20`, не лабораторный порог P&L; стоп/тейк уже в строке сделки.

### EP1-G01 RISK_PREDEFINED

Карта: **MD-EP-02**, **R-D-5** (также принцип 2 ATAS/Elearnmarkets в R-D-14).

Филл запрещён, если до входа не зафиксированы инвалидация (стоп) и размер. У узкого S-1 стоп = лой волны 5 **до** входа (`kontury/2026-08-30-s-1.md` §5.2–5.3). На таблице «Сделки»: у каждой из 6 строк поля `stop` и `take` заполнены на входе.

`allow_entry := edge_present ∧ risk_predefined ∧ size_predefined`

Диагностика (после HQ): PASS строки, если `stop` задан до филла и совпадает с `low_w5` плана S-1. Не выдумывать ширину стопа Дугласа: числовых ширин стопа в обзорах **нет**.

### EP1-G02 SIZE_ONE_UNIT

Карта: S-1 §5.2 (`long 1 unit`); инвариант `size(t) == size_plan` из **MD-EP-03**. Не усреднять, не мартингейл.

`size_plan` overlay = **1 unit** как в S-1 (полный кэш vs BH на входе, не «1 BTC»). Это замороженный план узкого S-1, не новая константа EP-1. Добавление к позиции и увеличение числа unit выше 1 — **fail**.

Полный кэш как scaffold S-1 ≠ реванш: реванш = `size(t) > size_plan` после убытка (MD-EP-03).

### EP1-G03 NO_SKIP_AFTER_LOSS

Карта: **MD-EP-04**, **MD-EP-08**, **R-D-11**.

Не пропускать следующий валидный край S-1 потому, что предыдущая сделка убыточна. Cherry-pick «эта похожа / эта страшная» запрещён, пока выборка открыта.

`skip_reason ≠ previous_loss`; `if signal_valid ∧ sample_open then must_execute`

Механический replay S-1 уже берёт каждый close-пробой при pos==0. Диагностика: после строк с `причина=stop` следующая строка таблицы, если она есть, не должна быть «пропущена из-за лосса». Новых сигналов overlay не ищет.

### EP1-G04 NO_SIZE_UP_AFTER_WIN

Карта: тот же `size_plan` (**MD-EP-03**); **R-D-13** (carefree без эйфории); цитата EBC в карточке MD-EP-03 про самоуверенность после выигрыша (S12). Отдельного MD-EP «после победы» в пакете нет — не изобретать второй ID размера.

Не увеличивать размер **потому что** предыдущая сделка выиграла. `size(t) == size_plan` на всей выборке. Press/anti-martingale поверх 1 unit — **fail**.

### EP1-G05 SERIES_NOT_LAST_PNL

Карта: **MD-EP-01**, **R-D-10**.

Судить процесс по серии при фиксированном определении края, не по P&L последней сделки. Return S-1 `-0.13396998649913494` **не** вердикт по Андрееву **и не** вердикт по Дугласу.

`evaluate(policy) := f(sample)`, не `f(last_fill)`.

### EP1-G06 SAMPLE_LT_20_INSUFFICIENT

Карта: **R-D-20**, **MD-EP-07**, **MD-EP-09**.

`n_trades = 6` (путь: `kontury/2026-08-30-s-1-replay.md`) `< 20` (Elearnmarkets Exercise / R-D-20). Series-level expectancy / «есть ли край» = **недостаточная выборка**, не FAIL.

Не кодировать `halt-after-N` как рабочий стоп: **MD-EP-09** как раз запрещает halt после k убытков внутри выборки. Порог 20 — минимум упражнения на *утверждение о серии*, не daily loss cap и не стоп S-1.

### EP1-G07 NO_AVG_NO_REVERSE

Карта: уже S-1 §5.3 («Не усреднять. Не переворачиваться в шорт.»). Overlay только фиксирует инвариант на тех же 6 long-only flatten-в-кэш сделках. Шорт после 5 вверх — другой контур, не EP-1.

## 10. Как работает механизм

Pipeline: **таблица «Сделки» S-1 (git) → гейты EP1-G01…G07 → отчёт соблюдения + статус выборки**. Барный каталог K-0 и метки lab D-1 **не** читаются заново для генерации входов.

Псевдокод — не реализация, не прогон:

```
# EP-1 diagnostic. NO market replay. NO new entries. NO R retune.
# Source of truth = git markdown, not local CSV.

trades = READ_TABLE("kontury/2026-08-30-s-1-replay.md", section="Сделки")
assert len(trades) == 6
# window already K-0; do not scan bars; do not call DETECT_5_DOWN_1H
# local local/data/s-1/trades.csv is NOT the archive input

size_plan = 1          # unit, S-1 §5.2, not a new EP-1 constant
N_plan_min = 20        # R-D-20 / Elearnmarkets Exercise, provenance not invention
sample_claim = INSUFFICIENT_SAMPLE if len(trades) < N_plan_min else PENDING_LAB_E

for i, t in enumerate(trades):
    G01 = t.stop is predefined and t.take is predefined     # MD-EP-02 / R-D-5
    G02 = size(t) == size_plan and not averaged             # 1 unit, no add, no martingale
    G03 = True
    G04 = True
    if i > 0:
        G03 = not skipped_because(trades[i-1].reason == "stop")   # MD-EP-04 / R-D-11
        G04 = not (size(t) > size_plan and trades[i-1] was win)   # no euphoria press
```
