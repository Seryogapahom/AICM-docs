## Метод (кратко)

1. S3 listing monthly `BTCUSDT` `1h` (IsTruncated=false).
2. GET каждого monthly zip + sibling CHECKSUM с `data.binance.vision`.
3. `sha256sum -c` (108 OK / 0 FAIL).
4. Unzip → один CSV без header → 12 колонок README.
5. Open time → datetime UTC: µs если magnitude ≥ 10^14 и/или файл ≥ 2025-01; иначе ms.
6. Concat, sort по open_time, drop exact duplicate timestamps.
7. Gap = соседние open_time (UTC datetime) с дельтой ≠ 1h; **без fill**.
8. Native assert: 3600000 ms до 2025-01-01, 3600000000 µs с 2025-01-01.
9. Метрики на окне [first open_time, last open_time] фактической серии.
